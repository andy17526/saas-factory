# Incident State

Multiples registros separados por `---`. Cada uno con un unico `INCIDENT_ID`.

```yaml
INCIDENT_STATE_V2_7:
  INCIDENT_ID: NONE
  SEVERITY: P3
  STATUS: CLOSED
  OWNER: NONE
  IMPACT: "Sin incidentes abiertos"
  NEXT_STEP_EXACT: "NONE"
```
