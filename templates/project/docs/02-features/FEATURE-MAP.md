# Feature Map

Indice de features del producto. Cada entrada enlaza a su nodo canonico.

## Reglas De Mantenimiento

- Toda feature registrada en `docs/00-system/knowledge-registry/features.yaml` debe tener nodo aqui.
- Toda feature debe tener entrada en `skill-routing.json` (lo verifica `skill-check`).
- Si una feature cambia comportamiento, contrato o riesgo, actualizar su nodo.
